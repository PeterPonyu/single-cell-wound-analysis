# Superseded combined collection

The two studies are now maintained and archived independently. Use the repository and software DOI corresponding to the study you intend to reproduce or cite.

- **Measurement construct validation:** [GitHub repository](https://github.com/PeterPonyu/wound-measurement-construct), [versioned release](https://github.com/PeterPonyu/wound-measurement-construct/releases/tag/v0.1.0), [software DOI 10.5281/zenodo.22872448](https://doi.org/10.5281/zenodo.22872448).
- **Held-out population dynamics:** [GitHub repository](https://github.com/PeterPonyu/wound-population-dynamics), [versioned release](https://github.com/PeterPonyu/wound-population-dynamics/releases/tag/v0.1.0), [software DOI 10.5281/zenodo.22872454](https://doi.org/10.5281/zenodo.22872454).

Each successor repository has its own Git history, manuscript, figures, analysis inputs, executable programs, citation metadata and independent Zenodo code archive. Neither depends on this combined collection or on the other successor repository.

This repository and its original release are retained as a historical snapshot. The successors are the current citation and reproduction targets. Author: Zeyu Fu. Software remains MIT; manuscripts, figures and source-study data retain their respective rights under NOTICE.
